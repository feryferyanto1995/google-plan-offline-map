# Google Plan offline map data

Static hosting for the Google Plan prototype's offline map: vector tiles, place search, walking, rail and Kyoto bus routing, attraction photos and traveller tips for central Tokyo and Kyoto. Everything is plain JSON and JPEG files, served by GitHub Pages, which allows other sites to load them (CORS `*`). Figma Make apps can load them at runtime.

- Demo: https://feryferyanto1995.github.io/google-plan-offline-map/offline-map/
- Module: `offline-map/offline-osm.js` (see `offline-map/README.md` for the API)

```js
import maplibregl from 'maplibre-gl';            // pin exactly 4.7.1
import 'maplibre-gl/dist/maplibre-gl.css';
const BASE = 'https://feryferyanto1995.github.io/google-plan-offline-map/';
const osm = OfflineOSM.create({
  maplibregl,
  dataUrl: BASE + 'offline-map/data/',
  tilesUrl: BASE + 'claude-prototype/data/',
  styleUrl: BASE + 'offline-map/data/style-streets.json',
  photosUrl: BASE + 'offline-map/',
});
```
